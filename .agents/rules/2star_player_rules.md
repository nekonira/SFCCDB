# ☆2選手 追加・計算・説明文統一ルール (2-Star Player Rules)

## 1. ☆2選手 レアリティ段階別能力上昇規約 (Rarity Stat Increment Offsets)

☆2選手がレアリティ昇格する際、18種（実質17項目）の詳細能力値の加算幅は以下のように固定計算する：

- **☆2 → ☆2+**: 各詳細能力 **+8** (累計 +8)
- **☆2+ → ☆2++**: 各詳細能力 **+8** (累計 +16)
- **☆2++ → ☆3**: 各詳細能力 **+18** (累計 +34)
- **☆3 → ☆3+**: 各詳細能力 **+9** (累計 +43)
- **☆3+ → ☆3++**: 各詳細能力 **+10** (累計 +53)
- **☆3++ → ☆4**: 各詳細能力 **+21** (累計 +74)
- **☆4 → ☆4+**: 各詳細能力 **+10** (累計 +84)
- **☆4+ → ☆4++**: 各詳細能力 **+11** (累計 +95)
- **☆4++ → ☆5**: 各詳細能力 **+25** (累計 +120)

※6大基本能力は `+3d`、総合値は `+18d`（各詳細能力加算値の和）自動連動計算する。

## 2. スキル・アビリティ説明文の統一規約 (Skill & Ability Description Formatting)

- ☆2選手を追加する際、カード画像やゲーム内テキストの簡易表記に関わらず、スキルおよびアビリティの名称・説明文はデータベース既存の標準フォーマット（☆3選手と同一の統一された正式名称・発動条件・発動エリア・効果表記）に自動補正して登録する。
- 例:
  - 『強引な中央突破』 → `発動エリア：前中・中中　/　発動条件：ドリブル時　/　突破力・キープ力UP`
  - 『懐の深いパサー』 → `発動条件：絶好調　/　ショートパス・キープ力UP`
  - 『技巧派ドリブラー』 → `発動条件：途中出場　/　突破力・ボールタッチUP`
